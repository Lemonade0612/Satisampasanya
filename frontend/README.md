# Sati User App

React user app at http://127.0.0.1:5173, also bundled by Capacitor for iOS.
Run `npm run dev` here to start only the frontend; start the backend separately.
Use **Sati: iPhone + backend (Device Hub)** with F5 from the root workspace
for the iPhone simulator and live updates. Build with `npm run build`;
web output goes to the root `dist/` directory used by Capacitor.
Dependencies and environment settings are managed at the repository root.
